# Legacy plans (Basic)

**Basic (Legacy)** is an older plan that we no longer sell. If you're still on it, you can keep it, but it has some limits our current plans don't have.

| | Basic (Legacy) | Starter |
| --- | --- | --- |
| Monthly API calls | 25,000 | 50,000 |
| Price | $49/month | $99/month |
| At the limit | **All requests blocked** | Throttled (requests keep flowing at a reduced rate) |

## Why are all my requests failing?

On Basic (Legacy), reaching your monthly limit **blocks** every API request. Each one returns `429 Too Many Requests — Monthly API limit reached` until your usage resets or you change plan.

## How do I fix it?

Move to **Starter** or a higher plan at https://billing.example.com. The change takes effect straight away and your requests start working again within a minute.

If you leave Basic (Legacy), you can't switch back to it.
